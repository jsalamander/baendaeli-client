# Local Web Fonts

Place licensed font files here so the kiosk can load them without relying on system-installed fonts.

Expected filenames:

- `akzidenz-grotesk-next-extend.woff2`
- `AkzidenzGroteskBlack.woff2`
- `NeueHaasDisplay.woff2`
- `MetalMania-Regular.ttf` (Google Fonts, SIL Open Font License; see `MetalMania-OFL.txt`)

The UI references these via `/fonts/<filename>`.
